2. Wyprzedzenie 5 min dla terminu +6 min → powiadomienie po ~1 min. Edytuj termin → stary alarm nie odpala.
3. Zablokuj ekran przed alarmem → zwykłe powiadomienie na blokadzie; odblokuj → przycisk „Wykonane” działa.
4. Restart telefonu przed alarmem → alarm nadal działa; restart po terminie → zaległe pokaże się po starcie.
5. Zmiana strefy czasowej w ustawieniach systemu → czas powiadomienia przesuwa się razem z wydarzeniem (czas ścienny).
6. Odmowa i ponowne przyznanie powiadomień → Ustawienia pokazują status, alarmy działają po przyznaniu.
7. Z Media Bar: karta kompaktowa → dotknięcie rozwija → „Przypomnij później” (np. 5 min) → wraca po 5 min; „Wykonane” → znika z listy nadchodzących i z centrum powiadomień.
8. Odinstaluj Media Bar → lista przypomnień nietknięta, kolejne alarmy jako zwykłe powiadomienia; zainstaluj ponownie → pasek wraca bez rekonfiguracji.
9. Wyłącz „Używaj Szczur Media Bar” → powiadomienia z banerem; włącz → znów pasek.
10. Aktualizacja APK Reminder (instalacja na wierzch) → przypomnienia zachowane, alarmy odtworzone.
